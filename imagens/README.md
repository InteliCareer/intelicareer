# Images & Diagrams

This folder contains all visual assets for the project.

## Contents

| File/Folder | Description |
|---|---|
| `architecture_diagram.png` | System architecture overview diagram |
| `data_model_erd.png` | Entity-Relationship Diagram (ERD) for the database |
| `wireframes/` | UI wireframes for each dashboard page |
| `kanban_mockup.png` | Job tracker Kanban board mockup |
| `skill_gap_mockup.png` | Skill Gap Analyzer UI mockup |
| `market_dashboard_mockup.png` | Market Trends Dashboard mockup |
| `logo/` | Project logo assets (SVG, PNG) |
| `screenshots/` | Product screenshots for README and documentation |

## Naming Convention

- Diagrams: `[type]_diagram.[ext]` (e.g., `architecture_diagram.png`)
- Wireframes: `wireframe_[page].[ext]` (e.g., `wireframe_tracker.png`)
- Screenshots: `screenshot_[feature]_v[version].[ext]`
