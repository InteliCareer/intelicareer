## Persona 1 — Alex, o Desenvolvedor em Transição

```
┌─────────────────────────────────────────────────────────┐
│  👤 Alex Souza, 27 anos                                  │
│  Desenvolvedor Backend Pleno — São Paulo, SP             │
│  Salário atual: R$ 7.500/mês                             │
│  Meta: conseguir emprego remoto internacional            │
└─────────────────────────────────────────────────────────┘
```

**Perfil:**
Alex tem 4 anos de experiência com Node.js e está querendo dar o próximo passo na carreira. Manda currículos pelo LinkedIn todo dia, mas não tem controle sobre o que enviou, em que estágio está cada processo, ou por que não recebe retorno. Não sabe exatamente quais skills precisa desenvolver para conseguir vagas internacionais.

**Objetivos:**
- Conseguir uma vaga remota acima de USD 80k
- Entender o que o mercado realmente exige para Senior
- Organizar seu processo seletivo sem usar planilhas

**Frustrações:**
- "Mando curriculo e não ouço mais nada"
- "Não sei se meu perfil está bom o suficiente"
- "O LinkedIn não me mostra o que os recrutadores procuram de verdade"

**Como usa o InteliCareer:**
- Cadastra cada vaga no Tracker assim que aplica
- Usa o Skill Gap para descobrir que Kubernetes e Redis são seus maiores gaps
- Consulta o dashboard de mercado para confirmar que Go está crescendo

## Persona 2 — Camila, a Profissional em Recolocação

```
┌─────────────────────────────────────────────────────────┐
│  👤 Camila Ferreira, 34 anos                             │
│  Engenheira de Dados Sênior — Remota                     │
│  Desempregada há 2 meses após layoff                     │
│  Meta: recolocação em até 60 dias                        │
└─────────────────────────────────────────────────────────┘
```

**Perfil:**
Camila foi impactada por um layoff em uma fintech e está em processo ativo de recolocação. Tem muita experiência mas o mercado mudou — empresas estão pedindo habilidades que ela não tem. Precisa de clareza sobre onde investir seu tempo de estudo.

**Objetivos:**
- Se recolocar rapidamente sem perder oportunidades
- Identificar as skills mais urgentes para aprender
- Acompanhar múltiplos processos ao mesmo tempo sem se perder

**Frustrações:**
- "Tenho muita experiência mas as vagas pedem coisas que eu não dominé"
- "Fico sem saber se devo estudar Spark ou dbt primeiro"
- "Perco o fio dos processos que estou participando"

**Como usa o InteliCareer:**
- Faz upload do currículo para extrair todas as skills automaticamente
- Usa os Insights para receber priorização de estudos
- Gerencia 15+ processos simultaneamente no Kanban
